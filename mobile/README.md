# Mobile

Ce dossier contient l’application mobile destinée aux **clients**.

Fonctionnalités prévues :
- inscription et connexion
- recherche de trajets
- réservation de billets
- consultation de l’historique
- suivi de position en temps réel
- partage de position (parents / contacts)
- envoi et suivi de colis
- contact du service après-vente

Le développement commence par le **module client uniquement**.
